Three jobs, one engine

Find. Compare. Guard.

Every mode is a view over the same primitive: retrieve the exact prose for the question, so the model reasons over the right lines instead of the whole repo.

Answer your repo

Ask in plain language; get the relevant passages cited to file:line, catching the paraphrase a grep misses, without reading whole files into context.

Spot contradictions

Surface every place a fact is stated (a price, a policy, a product name) and flag where the statements disagree. The drift a manual review misses in a large repo.

Guard against leaks

A deterministic lint that fails CI if an internal codename or a retired term reaches a public file. Exact-match over your term list, zero token cost, runs on every commit.

Install

Up and running in minutes.

Lint works with zero ML dependencies. Add the embeddings extra for semantic search and contradiction-finding.

terminal, bash
# the deterministic leak-guard, no ML needed
pip install concord-ai
concord init .          # scaffold rules.yaml (gitignored) + .gitignore it
concord lint .          # fail CI if a codename reaches a public file

# + semantic search / contradiction-finding (beta)
pip install "concord-ai[embeddings]"
concord index .         # build the local index (self-ignored)
concord radar .         # find where the same value disagrees across files
concord read "what have we said about pricing?"

Lint is stable. The semantic features work and are tested; treat them as beta.
